# Sohan Roast API

A lightweight, humorous, and fully customizable Node.js & Express REST API that serves up 200 custom-crafted dark/roast jokes specifically targeting my friend **Khaled Sultan Sohan**. Built for fun, testing, and API integration practice!

---

## 🛠️ Tech Stack

* **Runtime:** [Node.js](https://nodejs.org/)
* **Framework:** [Express.js](https://expressjs.com/)
* **Language:** JavaScript (ES6+)
